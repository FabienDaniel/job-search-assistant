# Translation glossary

Use these terms in every catalog so one concept keeps one name across screens.

## French (`fr.po`)

Address the user as "vous".

| English | French |
|---|---|
| résumé | CV |
| cover letter | lettre de motivation |
| Persona | Profil |
| scoring | notation |
| to score | noter |
| score (the number) | score |
| account | compte |

Spacing: a non-breaking space (U+00A0) goes before `:`, and a narrow non-breaking space (U+202F) goes before `;`, `?` and `!`.

Keep brand names as they are, such as LinkedIn, Telegram and Levels.fyi.
